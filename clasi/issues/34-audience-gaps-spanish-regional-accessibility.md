# Audience gaps: Spanish-language, South Bay/East County, accessibility

## Description

The equity story ("particularly for underserved communities") is not
visible in the data: South Bay has 8 records, East County 0, nothing is
in Spanish, and accessibility programming is nearly absent.

**Spanish-language / binational.** Zero Spanish-language STEM listings
exist anywhere in the county (verified absence, 2026-08-30). What we
can do: (a) carry a `bilingual`/Spanish-available flag — CMOD's
"Bilingual" events are already captured, SHPE's Noche de Ciencias and
Fleet's San Ysidro STEM Fair are hooks; (b) translate/surface es
descriptions for flagged records (LLM translation at export is cheap);
(c) evaluate listing El Trompo (Tijuana children's science museum) as
a binational entry — stakeholder call; (d) Casa de Amistad, MAAC, BLCI
partner outreach for program data.

**Regional balance.** Most of the South Bay/East County fix arrives
via other issues (County Parks ICS, Tijuana Estuary, Chula Vista
library via browser fetch, EAA Young Eagles at Brown Field, VEX/
Sweetwater, Eastlake FLL, Mission Trails, Mount Laguna, Wolf Center,
Botball at West Hills). This issue adds the measurement: a per-region
count in the yield report / site meta so regressions are visible, the
same way per-source yield is.

**Accessibility.** Fleet Accessibility Mornings (3rd Sat), Nat ASD
Mornings, CMOD Sensory Friendly Mornings are the county's offering —
make sure all three surface (currently 1 of 3), and add a
sensory-friendly/accessibility flag to the record + a site filter.

**Unresolved (record, revisit with Fleet's network):** tribal youth
programming (nothing found across 18 reservations — SCTCA, Kumeyaay
CC), Navy/military-family K-12 STEM (NIWC unverifiable), foster youth.
